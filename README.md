# Nasdaq 101 · Market Learning System

나스닥·매크로 투자 원리를 **읽기 → 적용 → 복습**의 한 흐름으로 익히는 정적 학습 웹앱입니다. 프로덕션 빌드나 서버 없이 `index.html`만으로 동작하며, 정적 호스팅에서는 오프라인 캐시와 설치형 앱(PWA)도 지원합니다.

## 기능

- **개인 학습 홈** — 전체 진도·누적 정답률·숙련 카드·남은 오답을 한 화면에서 확인
  - 오답·미학습·기억 강화 문제를 섞은 **오늘의 10문제** 자동 구성
  - 이어서 학습, 취약 카테고리 분석, 트랙별 진행도, 빠른 도구 제공
- **카드** — 206장의 플래시카드. 탭(또는 스페이스바)으로 질문 ↔ 인사이트 확인
  - **더 깊이** — 전 카드에 심층 층 내장: 작동 메커니즘(왜 그럴까) + 역사적 반례(이럴 땐 반대로) + 관련 용어 바로가기
- **퀴즈** — 상승/하락 방향 또는 이지선다 퀴즈. 카드별 시도·정답·연속 정답을 숙련도에 반영
  - **오답노트** — 틀린 문제가 자동 저장되며, `오답 N` 버튼으로 틀린 문제만 다시 풀기. 복습에서 맞히면 자동 제거
  - 오늘의 문제·취약 영역·챕터별 집중 세션과 세션 결과 화면 제공
- **학습 (매크로 스쿨)** — 4개 트랙, 14개 심층 챕터, 83개 시각화 섹션(약 121분)
  - 매크로 기초: 연준, 경제지표, 경기 사이클, 채권·수익률곡선, 달러·유동성
  - 기업과 지수: 실적 시즌, 나스닥 지수 구조, AI·반도체 사이클
  - 시장 판독: 시장 폭·수급, VIX·옵션, 멀티타임프레임 기술적 분석
  - 실전 운영: 폭락사, 리스크 관리, 시나리오 기반 플레이북
  - 트랙 필터·검색·이어보기·섹션별 진도·완독 표시·공식 자료 링크를 제공
  - 17종 HTML/SVG 시각화: 수익률곡선, 4분면, 금융 배관, 시나리오 트리, 공식 카드, 점도표, 사이클, 타임라인 등
  - **챕터 확인 퀴즈** — 각 레슨 끝에서 해당 주제 6문제로 이해도 확인, 틀린 문제는 오답노트로 연결
- **통합 자료실** — 전체 인사이트와 60개 용어사전을 한 화면에서 전환하며 탐색
  - 중요 카드를 저장하고 `저장됨` 필터로 나만의 복습 목록 구성
- **통합 검색** — `/` 키로 카드·챕터·용어를 한 번에 검색하고 해당 화면으로 바로 이동
- **AI 전문가 해설** — 카드 뒷면/퀴즈 결과에서 Gemini 기반 심층 해설 (선택 기능)
- **오프라인/PWA** — 정적 호스팅에서 핵심 파일 캐시, 홈 화면 설치, 네트워크 중단 시 재접속 지원

## 카테고리 (12개)

금리 & 연준 · 인플레이션 · 매크로 지표 · 실적 & 밸류에이션 · 환율 & 달러 · 원자재 · 채권 & 크레딧 · AI & 반도체 · 지정학 & 정책 · 시장 심리 & 수급 · 기술적 분석 · ETF & 투자전략

## 실행 방법

```bash
# 방법 1: 파일을 그대로 열기
open index.html

# 방법 2: 로컬 서버 (선택)
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages 등 아무 정적 호스팅에 그대로 배포할 수 있습니다 (저장소 설정 → Pages → 브랜치 선택).

## AI 해설 설정 (선택)

AI 해설은 Google Gemini API를 사용합니다.

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 API 키 발급
2. 앱 상단의 톱니바퀴 아이콘(또는 해설 버튼 클릭 시 안내 화면)에서 키 입력

키는 브라우저의 `localStorage`에만 저장되며 Google API 외 다른 곳으로 전송되지 않습니다. 키 없이도 학습 기능은 모두 사용할 수 있습니다.

## 키보드 단축키

| 키 | 동작 |
|---|---|
| `Space` | 카드 뒤집기 (Card 모드) |
| `←` / `→` | 이전 / 다음 카드 |
| `1` / `2` | 퀴즈 선택지 고르기 (Quiz 모드) |
| `/` | 카드·챕터·용어 통합 검색 |
| `Esc` | 모달 닫기 |

## 구조

```
index.html               — 앱 셸과 주요 내비게이션
css/styles.css           — 카드·레슨·시각화 기본 스타일
css/redesign.css         — 대시보드·반응형 도크·통합 탐색 디자인 시스템
js/data.js               — 학습 카드 데이터 + 기본 레슨 + 카테고리 엔진 + 용어사전
js/lessons-advanced.js   — 확장 커리큘럼·학습 트랙·공식 자료
js/app.js                — 학습 상태·숙련도·검색·HTML/SVG 시각화
manifest.webmanifest     — 설치형 웹앱 메타데이터
sw.js                    — 오프라인 핵심 파일 캐시
tests/                   — 데이터·앱 셸·DOM 사용자 흐름 회귀 검증
```

## 데이터 검증

```bash
npm install
npm test
```

프로덕션 앱에는 런타임 라이브러리 의존성이 없습니다. `happy-dom`은 자동 회귀 검증에만 사용합니다.
